Previsão do Tempo
Script em Python que consulta a API do OpenWeatherMap e exibe a previsão do tempo de uma cidade no terminal.

 Tecnologias
- Python 3
- requests
- python-dotenv

 Como executar
1. Crie uma conta na [OpenWeatherMap](https://openweathermap.org/api) e gere sua API Key.
2. Crie um arquivo `.env` na raiz do projeto com:
   ```
   API_KEY=sua_chave_aqui
   ```
3. Instale as dependências e rode:
   ```bash
   pip install requests python-dotenv
   python clima.py
   ```

Funcionalidades
-Busca a temperatura e a descrição do clima de uma cidade
-Converte a temperatura de Kelvin para Celsius
-Exibe o resultado no terminal
